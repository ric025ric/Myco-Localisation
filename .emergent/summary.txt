<product_requirements>
The Myco Localisation application is an Android app for mushroom foragers. Its primary function is to allow users to save GPS locations of mushroom spots, including details like mushroom type, notes, and photos. Users can view their saved spots on a list or a map.

**Key Features Implemented:**
-   **Spot Management:** Create, view, update, and delete GPS-tagged mushroom spots.
-   **Mushroom Guide:** A searchable, admin-manageable database of mushrooms with details, photos, and lookalikes.
-   **Admin Panel:** PIN-protected screens for adding, editing, and deleting mushroom entries in the guide.
-   **Multi-language Support:** French and English.
-   **Offline Mode:** Users can save new spots without an internet connection. These spots are stored locally and can be synchronized with the server later.
-   **KML Import:** Users can import spots from a KML/KMZ file exported from Google My Maps.
-   **Enhanced GPS Accuracy:** Location requests are set to high accuracy for precise spot marking.

**Current Problem & Security Enhancement:**
The app initially identified users by a self-reported pseudo, creating a major privacy and security issue: any user could enter another's pseudo and access their spots. The current development effort focuses on replacing this with a persistent, device-unique ID (UUID) to ensure each user's data is private and secure. To prevent data loss upon app re-installation, an import/export feature for this user ID is also being developed.
</product_requirements>
